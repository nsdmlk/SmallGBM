Why SmallGBM?

Robust Leaf Weights

Median for small leaves, inverse-distance weighted mean for larger ones, plus signal-adaptive shrinkage. One outlier can't destroy the estimate.

C Core

Histogram-based tree with 256 quantile bins, compiled on install. 2.7× faster training and up to 5× faster inference than XGBoost on small data.

scikit-learn Compatible

Drop-in replacement: same fit, predict, predict_proba interface. Works with GridSearchCV, pipelines, everything.

Getting Started

Installation

# pip (compiles C core automatically)
pip install smallgbm

Requires a C compiler on PATH (cc, clang, or gcc). On macOS: xcode-select --install.

Classification — 5 lines

from smallgbm import SmallGBMClassifier

model = SmallGBMClassifier()
model.fit(X_train, y_train)
proba = model.predict_proba(X_test)
preds = model.predict(X_test)

Regression is not recommended. SmallGBMRegressor exists in the API but is not validated — robust leaf regularization, tuned for classification, does not transfer. See Limitations.

When NOT to use SmallGBM

Regression

SmallGBMRegressor exists in the API but is not validated and not recommended. On 26 small regression datasets it scores normalized MAE of 0.61 vs 0.39 for XGBoost (mean rank 4.46 vs 2.31). The robust leaf regularization, tuned for classification, does not transfer to regression.

Large datasets (n > 1000)

SmallGBM is designed for small data. On larger sets, XGBoost and LightGBM are optimized for scale and will train orders of magnitude faster. Example: at n = 200k, XGBoost reaches 0.923 AUC in 0.71s, while SmallGBM gets 0.884 in 69s. This is expected — robust leaf regularization is a small-sample technique.
